# 🎓 Student Learning Pathway Dashboard (Python)

This project is a **Python-based learner management system** that tracks module completion, calculates performance, recommends next modules, and determines certification eligibility.  
It provides an interactive console application with a summary dashboard for all learners.

---

## 🚀 Features
- Define modules and their prerequisites.
- Add learners interactively with validation.
- Track completed modules and scores.
- Calculate learner averages and performance classification.
- Recommend eligible modules based on prerequisites.
- Check certification status (all modules completed).
- Display a dashboard with:
  - Learner summary table
  - High achievers list
  - Top-performing learner
