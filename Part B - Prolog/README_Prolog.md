# 📘 Learner Module Eligibility System (Prolog)

This project is a **Prolog knowledge base** that models learners, modules, prerequisites, and certification rules.  
It allows you to query which learners are eligible to enroll in modules, what modules are recommended for them, and who qualifies for certification.

---

## 🚀 Features
- Define learners and modules with unique IDs.
- Track completed modules for each learner.
- Specify prerequisites between modules.
- Check **eligibility** for enrollment.
- Generate **recommended modules** for learners.
- Verify if a learner is **eligible for certification**.

---

### 2. Save the Code
- Copy the Prolog code into a file named `main.pl`.
- Place it in a working directory.
